# DayDots

DayDots is an accessibility-focused task management application designed to help individuals with cognitive impairments manage daily routines with confidence and clarity.
Built around simplicity, structure, and supportive cues, DayDots helps users break down their day into manageable tasks, track progress, and reduce overwhelm through clear visual design and routine-based planning.

## Why DayDots?
Many people struggle with planning, memory, and task follow-through—not because they lack ability, but because traditional task managers are too complex, cluttered, or cognitively demanding.

DayDots was designed to address that challenge by making daily planning:
- clear and low-stress
- visually simple and easy to scan
- supportive for routine-based thinking
- encouraging without being overwhelming

## Features
- Daily routine planning
- Simple, accessible task lists
- Clear visual hierarchy and reduced cognitive load
- Progress tracking for completed tasks
- Routine reminders and structure for the day
- Designed with accessibility in mind
- Easy-to-understand interactions for users who benefit from clarity and repetition
- Focus on reducing confusion and decision fatigue

## Tech Stack

DayDots is primarily built with Dart, with native integrations for platform-specific functionality.

- Dart
- Flutter-style app architecture
- Native modules using C++/CMake and Swift for platform support
- Mobile-first design with accessibility considerations
